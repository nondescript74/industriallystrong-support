# industriallystrong-support

Static support and privacy pages for Zahirudeen Premji's apps, served by GitHub Pages at
**https://support.industriallystrong.com** (the Support and Marketing URL in App Store Connect).

| Path | Page |
|------|------|
| `/` | App list |
| `/kanjikanatrainer/` | KanjiKanaTrainer |
| `/cnz-japan-2027/` | CnZ Japan 2027 |
| `/reczipes2/` | Reczipes2 |
| `/privacy/` | Privacy for all three (anchors per app) |

Plain HTML + one stylesheet, no build step. `CNAME` holds the custom domain.

DNS (Cloudflare): `CNAME support → nondescript74.github.io`, DNS only (grey cloud), the same pattern as `z`.
